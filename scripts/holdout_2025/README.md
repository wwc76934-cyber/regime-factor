# 2025 留出期、模型解释及模拟账本

这套脚本复用项目已有开发期数据和成交引擎。只补 2025 数据，原数据和报告无需重下或覆盖。默认运行日期边界是 2025-01-01 至 2025-12-31，净值基于 2024-12-31 收盘的同额现金。第一个模拟调仓日为 2025-01-06。脚本不会读取 2026 年行情。

从项目根目录执行：

    .\.venv\Scripts\python.exe -m pip install lightgbm==4.6.0 scipy==1.17.1
    .\.venv\Scripts\python.exe -B .\scripts\holdout_2025\fetch_holdout_2025_inputs.py --project-root . --cache .\data\raw\holdout_2025 --workers 2
    .\.venv\Scripts\python.exe -B .\scripts\holdout_2025\run_holdout_2025_evaluation.py --project-root .

如果已经显示 Cache ready，跳过采集。若分片补采中断，用采集命令加 --resume --workers 1；仅重试缺失的文件。若只缺 H00300，使用 --index-only；若已有经核对且覆盖完整日期的镜像 CSV，可加 --index-mirror-csv 路径。脚本不会用价格指数冒充全收益指数。本轮采用中证官方 H00300，共 244 个收盘点位，包含 2024 年末归一化锚点。

脚本把冻结配置和 SHA-256 保存到输出目录，成功后写 completed.json。同一目录不能再次揭盲。复现可指定新的 --output-dir，并与原结果比较；严禁用 2025 年收益重新挑模型或参数。注册是本地时间戳记录，不是第三方预注册。监督学习沿用旧缓存和最近 104 个成熟周；原 2024 年最后一个没有标签的信号继续缺省，2025 标签只在结束日开盘后才可能进入训练。新代码 sz.302132 的后复权序列仅自 2025-02-17 起使用，不把更名前不复权数据伪装成后复权。

默认产物写入 reports/holdout_2025：

- reports/holdout_summary.csv、weekly_rank_ic.csv、holdout_nav.parquet：14 组净收益、基准、回撤、费率、换手和 51 周 Rank IC。52 次调仓与 51 个可评价 IC 周的差来自最后一次持仓没有留出期内下一次调仓开盘。
- explain/：2021–2025 生效权重、主效应、状态增量、市场状态原值，外加 LightGBM 逐周 gain/split、分样本占比和分状态预测分差。预测分差不是实际收益、因果效应或单因子独立贡献。条件组采用筛选期阈值，高低因子组为当周百分位的前后约 20%。
- simulation/：2025-12-26 收盘信号、12-29 模拟调仓的缓冲目标和买卖清单，含分数、因子百分位、状态读数、入选原因、申请量和模拟成交量。SQLite 含最后调仓目标、最后调仓订单、全期订单及公司行动。另存 2025-12-31 信号的未缓冲 Top 30；它计划在 2026-01-05 执行，但不计入 2025 交易。
- audit/：标签成熟链接、分红公告补录、行情参考价差异和未核验持仓暴露。实际持仓涉及未核验公司行动时，不发布收益。

账本的 record_type 是 historical_paper_replay。本次没有创建 2026 年实时纸面组合，也没有向券商提交订单。若课程要求真实前向记录，应从当前最新可用信号开始单独建账，记录当时生成的计划以及下一开盘的实际模拟结果，不能事后把本账本改标为前向。
