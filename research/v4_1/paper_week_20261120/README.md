## 本地复跑

在项目根目录依次运行下列命令。需要本地保留开发期缓存和[盲测封存文件](../final_2026/holdout_seal.json)。采集器支持从现有缓存续跑，后两步离线运行。

```powershell
.\.venv\Scripts\python.exe -B .\scripts\v4_1\collect_paper_week_20261120.py
.\.venv\Scripts\python.exe -B .\scripts\v4_1\prepare_paper_week.py
.\.venv\Scripts\python.exe -B .\scripts\v4_1\run_paper_week.py
```

生成程序逐股核对续接前的持仓和历史订单、核对封存净值、复现已有信号，并检查本周现金、成交费用、公司行动和换仓日期。历史盲测和本期预估单分开归档。[冻结盲测报告](../final_2026/HOLDOUT_REPORT_2026.md)
