# V4 深度门控多因子研究

V4 检验一个问题：20 日量价序列、跨股注意力和市场门控能否提供 V3.1 手工因子之外的预测信息。传统对照锁定为 `92d9b00` 的非负 Ridge 与原 Huber 等权组合，10 bp 开发期 IR 为 0.5337。

## 第一阶段验收

从本地缓存生成 2015-01-09 至 2025-12-26 的 562 周序列。每周取当时的 300 只成分股，每股最近 20 个交易日、7 个通道。168,600 个股票周键及其标签与 V3.1 的 h5 缓存逐条一致。随机抽取的 10 周同时对照原始成分名单、不复权日线和当日截面标准化的日内收益。全部周的序列截至信号日，有效标签的退出日晚于信号日。[数据核验](results/step1/verification.json)

日收益取后复权收盘价，振幅、日内收益和收盘位置取相互一致的不复权行情。相对收益取 H00300 全收益指数。指数缓存从 2015-01-05 开始，此前窗口的相对收益保留缺失掩码。通道缺失率为 1.90% 至 2.22%，缺失项标准化后填零。562 周中有 548 周具备完整的五维状态。训练和打分要求状态完整，当前交易资格按信号日行情确定，未来标签只用于监督与评价。

## CPU 实测

在 Ryzen 5 5500U 上使用 CPU 版 PyTorch 2.15.0 和 4 个计算线程。首个重训信号为 2017-01-06，使用 69 周训练、2 周隔离、16 周验证。三种子分别早停并恢复最佳检查点。实际结构依照方案列出的卷积、四头注意力、门控和评分层实现。

| 配置 | 参数量 | 首轮三种子实测 | 按后续训练批次数推算的 39 轮耗时 |
|---|---:|---:|---:|
| 24 维，批量 16 周 | 5,733 | 50.3 秒 | 89.9 分钟 |
| 16 维，批量 32 周 | 3,001 | 42.2 秒 | 63.7 分钟 |

下一阶段使用 16 维、批量 32 周配置。耗时估算假定后续季度的早停轮数接近首轮，只涵盖主模型训练。后期窗口可增至 260 个成熟周，另跑消融会增加耗时。开发期 460 个预测周的独立 Rank IC、Top 30 命中率以及与两个传统模型的相关性，须在完整滚动预测后评价。2026 留出期继续封存。[张量与测速明细](results/step1/dataset_and_benchmark.json)

## 本地复现

在项目根目录用已安装 CPU 版 PyTorch 的虚拟环境运行：

```powershell
.\.venv\Scripts\python.exe -B scripts/v4/build_v4_sequence_dataset.py
.\.venv\Scripts\python.exe -B scripts/v4/verify_v4_dataset.py
.\.venv\Scripts\python.exe -B scripts/v4/benchmark_v4_cpu.py
```

生成的压缩张量位于 `research/v4/cache/weekly_sequences.npz`。其 SHA-256、逐通道缺失率、训练窗口日期和各随机种子的早停记录随测速明细保存。

## 第二阶段的复现与评价口径

在项目根目录运行以下两条命令。第一条按每 12 个预测周重训，按种子分别在当周可评分股票中标准化，再对三个种子的股票分数取均值。已完成的重训窗口可复用；检查点目录由数据、源代码、训练设置和 PyTorch 版本共同确定。

```powershell
.\.venv\Scripts\python.exe -B scripts/v4/train_v4_deep_model.py
.\.venv\Scripts\python.exe -B scripts/v4/audit_v4_signals.py
```

独立门槛在 V4 自身当时可评分的股票池上评价。与传统模型的相关性在同周三者均有预测的股票上计算，并另列共同股票池的预测表现。消融固定在首个季度，分别去掉跨股注意力和市场门控，同窗、同种子重新训练。两种去除实验的评分只用于该季度的结构对照。

**第二阶段结论为 No-Go。** 459 个有成熟标签的预测周中，独立 Rank IC 为 0.0159，Top 30 命中率为 11.07%。与非负 Ridge、原 Huber 的平均截面秩相关分别为 0.1925、0.1379，两项相关性门槛均通过。2023–2025 段 Rank IC 为 −0.0261，Top 30 相对 H00300 的平均五日费前收益差为 −11.8 bp。按准入规则停在信号审计阶段，2026 留出期继续封存。[完整报告](results/step2/REVIEW.md) · [验收记录](results/step2/decision.json)
