# 沪深 300：三因子正则、交互和 LightGBM 对照

适用于已有本项目 2020–2024 开发期缓存的环境。按[仓库说明](../../README.md#本地运行)生成旧三因子全排名、沪深 300 全收益指数及历史成分股等权基准，再从项目根目录运行：

    .\.venv\Scripts\python.exe -m pip install lightgbm==4.6.0 scipy==1.17.1
    .\.venv\Scripts\python.exe -B .\research\three_factor_experiments\run_three_factor_experiments.py --project-root .

第一步安装依赖需要网络，实验运行只读取本地文件。默认输出 reports/three_factor_experiments，可指定 --output-dir 写到其他实验目录。代码不修改原有回测或 2025 留出数据。

- 三因子输入为原模型生成的因子截面百分位。三项市场状态保持原定义；每个训练窗口内按历史状态标准化并截断至 ±3，不残差化广度。
- 三因子分离正则保留 9 个交互项，主效应均用 0.05，状态惩罚分别为 0.5 和 1.0；另设同主效应惩罚 0.05 的无交互对照。
- 核心交互仅使用此前通过筛选门槛的 RET_5 × 市场波动和 VOL_60 × 上涨广度，所有系数统一惩罚 0.01，用于和原全交叉版比较。RET_5 × 指数趋势未过跨段一致性门槛；本实验不引入额外个股因子。
- LightGBM 回归未来一周收益的截面百分位（与 Ridge 同一标签，截面中心化只改变常数）。使用固定的 64 轮、树深 3、最多 7 个叶子、每叶至少 300 条样本的配置。三输入版用于隔离市场状态输入的增量，六输入版用于和状态 Ridge 比较。训练按周等权，不用验证段提前停止。
- 模型沿用同一只股票池、52–104 个已成熟标签周、53 周等权预热。成本和缓冲在打分后单独改变：全部模型跑无缓冲和前 45 缓冲，各两档单边费率（10/20 bps）；原状态版另跑前 50、55 缓冲。保留规则基于真实持仓，不增设补仓候选。
- 组合评价 2021-01-18 至 2024-12-31（锚点为 2021-01-15 收盘）。周度 Rank IC 用有效标签的 199 个拟合周，其中 99 周在筛选段、100 周在开发验证段。执行层有 202 次调仓。研究结构参考了已知开发结果，不是严格样本外检验。
- 同分时按股票代码升序；六输入树另按代码降序做敏感性对照，只改拟合期同分排序，预热和模型分数不变。此对照不参与参数选择。
- 本次回测在内存中补入中国核电 2024-12-02 特别分红（税前每股 0.02 元），以公司公告 2024-082 为依据。补录对所有模型生效，不改仓库中的原事件表；如原表已补录，脚本核对日期和金额以防重复。

主要产物：reports/execution_ablation.csv、reports/benchmark_excess_metrics.csv、reports/yearly_returns.csv、reports/model_rank_ic_by_split.csv、reports/lightgbm_weekly_fit.csv、reports/unresolved_exposures.csv 和 run_config.json。完整排名、目标持仓、Ridge 动态权重、逐周 IC、日度净值另存为 Parquet。
