# V3.1 Step 3 指数增强优化与执行审计

**No-Go。** 2017–2025 年完成 32 条组合账本。双周和月频的 50/50 融合在 10 bp、20 bp 两档均跑赢 H00300，但没有任何双周或月频实验同时达到两档费率下的净超额、周等效双边换手不超过 15%、进攻期成交 Beta 达标率至少 80% 和账本安全要求。2026 保留段继续隔离。

## 组合与执行设定

指数增强以点时 FloatMV 作为主动权重锚点，连续权重满仓，单股不超过 6%，偏离锚点不超过 3 个百分点。用已成熟的前 52 周预测 IC 校准预期收益，按 0.02 至 0.08 截断。收益单位是持有期收益，风险是市场因子与个股残差方差之和，风险厌恶设为 6。优化代价等于撮合的单边费率。结构化对偶求解在三种 Beta 约束样例中与 SLSQP 交叉核验。

Ridge 与 Huber 每个信号周分别标准化，融合权重各 50%。门控网络不参加组合实验。所有策略以实际 5、10 或 20 个交易日为调仓间隔，在开盘使用此前最新的周信号。周频测试 EMA 0.3 与 0.5，另将 EMA 0.3 原参数应用于双周和月频作为降换手敏感性。控制组比较静态与动态 Beta、是否开启 η 缓冲、以及保持前 30 只股票的无基准优化。

连续解经限价、停牌、手数、成本和剩余资金映射后进入 V3 账本。Beta 用成交后开盘仓位、当时已知个股 Beta 和扣除成交费后的账户净资产计算。含未知个股 Beta 时，在 0.2 至 2.2 下做上下界检查。周等效双边换手为全期日度成交额除以当日开盘资产的累计值乘以 5，再除以交易日数。费率同时进入优化目标和成交账本，因此两档费率可能产生不同的交易路径。比较为研究模拟。

## 三基准与账本例外

H00300 是正式基准。同期 H00300、FloatMV 与 CSI300_EW 的累计收益分别为 +72.45%、+92.29% 与 +46.31%。全周期与逐年三套超额、年化超额、IR、超额回撤和日胜率已输出。基准桥接把相对 H00300 的累计超额精确拆成相对 FloatMV 的累计超额及 FloatMV 与 H00300 的基准差。例如月频融合 20 bp 相对 H00300 为 +9.92 个百分点，相对 FloatMV 为 -9.91 个百分点。仅凭该行无法把官方基准超额归到选股。
